# NGS-Assay-Validation-Framework

## Project Description 

Develop an end-to-end, R-based framework for evaluating the analytical performance of next-generation sequencing (NGS) assays using publicly available sequencing datasets. The project leverages Genome in a Bottle (GIAB) benchmark samples for accuracy assessment and 1000 Genomes Project sequencing data for robustness testing and quality control analyses. The framework automates sequencing quality assessment, coverage analysis, variant concordance evaluation, and performance metric reporting. 

## Project Objectives 

Create a reusable validation platform capable of assessing analytical performance of NGS datasets and generating validation-ready reports with minimal user intervention. Additional goals include comparing variant calls against benchmark truth sets, evaluating sequencing depth impacts, demonstrating reproducible workflows, and automating publication-quality reporting. 

## Example Analyses 

Sequencing QC Assessment: mean coverage, coverage uniformity, mapping statistics, and breadth of coverage. Variant Accuracy Assessment: true positives, false positives, false negatives, sensitivity, precision, and F1-score. Coverage Optimization: downsample sequencing data and assess variant recovery. Automated Reporting: generate HTML or PDF validation reports with metrics, figures, and documentation. 

## Skills Demonstrated 

Bioinformatics (BAM and VCF analysis, variant benchmarking, NGS QC), Statistics (classification metrics, concordance analysis, coverage modeling), Software Development (workflow automation, reproducible pipelines), and Scientific Communication (technical documentation and validation reporting). 

## Resume Version
